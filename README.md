# 💬 Chatverse – Real-Time Chat Web App

Chatverse is a modern full-stack real-time chat application that enables users to connect, communicate, and collaborate instantly. With support for media sharing, real-time notifications, infinite scrolling, and an analytical admin dashboard, Chatverse delivers a seamless chat experience built on top of robust technologies.

---

## 🚀 Features

- 🔐 **User Authentication** (JWT based)
- 📎 **Share Attachments** – Send images, audio, and more
- 🔁 **Infinite Scrolling** – Older messages load as you scroll up
- ⚡ **Real-Time Chat** – Powered by Socket.io
- ✍️ **Typing Indicators** – See when someone is typing
- 🔔 **Live Notifications** – New message alerts, typing status, and more
- 📊 **Admin Dashboard** – View analytics, user stats, and system logs
- 🎨 **Framer Motion** – Smooth UI animations for a better experience

---

## 🛠️ Tech Stack

| Layer      | Tech Used                    |
|------------|------------------------------|
| Frontend   | React.js, Material UI (MUI)  |
| Backend    | Node.js, Express.js          |
| Database   | MongoDB Atlas                |
| Real-Time  | Socket.IO                    |
| Cloud      | Cloudinary (for file uploads)|
| Animations | Framer Motion                |
